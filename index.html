Human Minority is a deterministic, source-available verification layer for AI coding agents and agentic coding workflows. It binds claims and verifier results to the exact candidate being checked, while keeping the producing agent separate from acceptance authority.

Separate production from proof.

AI coding agents can write code, run tools and report success. Human Minority treats those reports as claims until independent evidence is checked against the exact candidate.

Claim

What the producing agent says happened.

Evidence

What can be independently checked and bound to the candidate.

Verification

Deterministic checks over the required result set and trusted verifier identities.

Authority

The human or policy decision that may accept, merge or deploy.

Run the public verification path.

The current public artifact provides an installable CLI, exact candidate-byte identity with SHA-256, claim/evidence/result contracts, a runnable verification vertical and public integrity checks. Runtime dependencies are Python standard library only.

git clone https://github.com/Rud0lfoRRP/Human-Minority.git
cd Human-Minority
python -m pip install --no-deps .

human-minority --version
human-minority inspect
human-minority verify \
  --candidate examples/public_verification/candidate.txt \
  --bundle examples/public_verification/bundle.json

Current public boundary

Human Minority is in early development. The public V1 verifies portable claim/evidence/candidate bindings and decision logic. It does not claim to provide secure execution of arbitrary untrusted repositories, production provider orchestration, cryptographic verifier identity attestation, autonomous repair execution, merge authority or production secret custody.
